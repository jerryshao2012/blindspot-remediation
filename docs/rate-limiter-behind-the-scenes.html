Transition: “Let’s start with the central blindspot: why green test suites fail on stateful code.”

The blindspot

Green tests are not behavioral truth.

01 / BOUNDARY

Exact window boundaries hide inside state. A request at $t=0.0$ dropped at $t=60.0$ vs $t > 60.0$ passes standard tests but violates SLA contracts in production.

02 / VACUITY

100% coverage can be vacuous. Code can execute every line without asserting invariant correctness. Only mutation testing proves tests detect subtle defects.

03 / GOVERNANCE

Automated repair must be bounded. An AI assistant must never loop indefinitely, edit its own evaluation tests, or modify source code without human cryptographic authorization.

The Release Gate Invariant

Release Gate enforces behavioral depth through mutation gauntlets and ensures automated repair remains inside strict human-approved budgets in disposable sandboxes.

0:00–0:50 · The Three Defect Traps. (1) Off-by-one boundary bugs that evade standard unit tests; (2) False confidence from 100% line coverage that doesn't actually assert invariants; (3) Unbounded AI agents that hallucinate or rewrite tests to force green checkmarks.

0:50–1:30 · The Solution. A 10-layer Quality Gauntlet backed by mutation testing and an auditable, bounded repair loop.

Transition: “Step 1: defining the sliding window specification.”

01
Step 1 · specification

One operator changes the window contract.

t = 0.0s · hit
t = 60.0s · still active
t > 60.0s · expired
>=

C0 defect: drops the hit at the exact boundary ($t = 60.0$). Prematurely resets quota.

<=

C1 retry: inverts the condition, dropping active hits and retaining expired ones.

>

C2 correct: expires strictly when $\text{now} - \text{hit} > \text{window}$. Restores SLA.

spec.md · src/ratelimiter/__init__.py (_prune)

0:00–0:50 · The Mathematical Contract. In a sliding window rate limiter, a hit recorded at t=0 remains active across the entire closed interval [0, 60]. It must only expire when age strictly exceeds 60 seconds (t > 60).

0:50–1:30 · The Defect Operators. Changing > to >= drops requests at the exact 60.000s boundary. Changing to <= inverts the queue. We will see how the gate catches both.

Step 7 · governance gate

Automation can repair — inside explicit authority.

Approved Paths Only

Authority is restricted to exactly README.md and src/ratelimiter/__init__.py. Editing tests or policy triggers immediate termination.

Attempt Cap Budget

The repair session is strictly limited to 2 attempts. If C1 and C2 both fail, the session aborts and escalates to engineering.

Disposable Sandbox

All repair attempts execute in an isolated temp workspace (release-gate-repair-ws-...). The source worktree remains immutable at C0.
